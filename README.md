# Hytale Builder+

**Quality-of-Life mod for Hytale**

With this mod, creating the "wrong" structural block is no longer a problem.  
You can always convert it back to its original base material or even switch to a different material variant directly at the **Builder's Workbench**.

## Features

This mod adds a large number of new recipes to the **Builder's Workbench** (Structural Crafting).  
Existing recipes remain completely unchanged.

### 1. Reverse Recipes
Convert most crafted structural blocks back into their base material.

Examples:
- `Rock_Stone_Cobble_Stairs` → `Rock_Stone_Cobble`
- `Wood_Lightwood_Wall` → `Wood_Lightwood_Planks`
- `Rock_Stone_Cobble_Half` → `Rock_Stone_Cobble`

### 2. Direct Material Conversion Recipes
Upgrade or change material variants without dismantling everything.

Examples:
- `Rock_Stone_Cobble_Stairs` → `Rock_Stone_Brick_Stairs`
- `Rock_Stone_Cobble_Wall` → `Rock_Sandstone_Brick_Wall`
